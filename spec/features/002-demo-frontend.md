# 002 SituationSHIT 演示前台

状态：READY（独立的 mock 前台范围，不代表真实后端/钱包/合约已交付）。
关联任务：T010；依赖 T002 的已冻结规则。负责人：skelitalynn，AI 助手实施。

## 需求来源与范围

2026-09-19 用户要求“先把前台给跑出来”，用于演示 PPT；未接入的后端接口先用 mock，后续替换为真实服务。首版提供七类页面、可点击业务流程、场景切换和截图资料。T003 的前端初始化由本任务完成，API/合约工程及真实网络验收仍按原任务实施。

## 功能行为

- React + Vite + TypeScript，中文，浅色玫红品牌，桌面侧栏/移动底栏；首页、创建、邀请、关系主页、争议、监督、结束页面均有地址可直接打开。
- 显著固定“演示模式 · 模拟数据”标识；不调用真实钱包、不发后端请求、不产生链上交易、不伪造可浏览的交易哈希。用户角色切换仅演示，不作为真实认证。
- mock service 为异步接口，视图不得直接修改 fixture。以独立类型/服务适配层隔离数据；未来 HTTP/钱包实现替换 service，不在 UI 混入网络状态判断。
- 默认准备进行中关系（小夏/一帆，50 USDC 恢复基金 + 20 USDC 保证金/人）和三位监督人；所有身份/事件均为演示数据。可创建新关系、模拟双方签署及入金、发正式确认、演示时间推进到申诉/投票、好友两票裁决、正常结束；付款结果保持001资金规则。
- 设独立演示控制面板：切换角色、预设进行中/待签署/争议/已结束场景、模拟时间推进、重置。只能从标明模拟的控制面板跳过等待/预填条件，业务按钮仍遵循各状态前置条件。
- 浏览器 localStorage 保存演示状态，刷新可继续；坏数据/版本不兼容安全重置并提示。首次加载、操作中、错误、空状态有明确反馈。失败不得提前更新成成功。
- 截图模式只收起演示控制操作，保留小型模拟数据标识，避免把截图当真实链上证明。为 PPT 输出桌面/移动关键页 PNG。
