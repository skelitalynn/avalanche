# 003 前台后台适配层

状态：READY。关联任务：T024。负责人：本次对话用户，AI 助手实施。

## 需求来源与目标

2026-09-19 用户要求拉取远程仓库最新修改，并把前台调整为可正常接入后台的状态。远程 `main` 已提供 React/Vite 前台、`SituationService` 视图契约和冻结的 HTTP API v1，但尚无 `apps/api` 后台实现。本任务交付可配置、可测试的真实 HTTP/SIWE 适配边界，不把不存在的后台或链上写入伪装成已完成。

## 范围

- `VITE_DATA_MODE=mock|api` 决定注入本机 Mock 或 HTTP 服务，默认保持 Mock 演示可运行。
- API 模式按 `/api/v1` 调用公开的 `health`、`config`，所有请求携带 Cookie；开发服务器可将 `/api` 代理到单独后台。
- 未登录时由用户点击连接兼容 EIP-1193 的钱包，检查/切换 Fuji，依次请求 SIWE challenge、钱包签名和 verify；页面不接收私钥。
- 登录后读取关系列表及详情，把冻结 API 的字符串金额、Unix 秒和链上枚举映射到现有视图模型；可用环境变量指定关系地址，否则选择列表第一项。
- 后台不可用、非 Fuji 配置、401、空关系列表、钱包拒绝和未知状态均显示明确失败，不回退到 Mock 成功。
- 尚无合约 ABI、部署地址及完整后端写接口时，创建、签署、入金、投票和结算等操作明确拒绝；本任务只宣称连接、认证与读取适配完成。

## 验收标准

| 编号 | 前置与操作 | 可观察预期 |
| --- | --- | --- |
| AC-003-01 | 默认配置启动前台 | 使用 Mock，原演示和测试保持可用 |
| AC-003-02 | API 模式且后台不可达 | 显示后台连接失败与重试，不显示模拟关系为真实数据 |
| AC-003-03 | API 返回 401 | 显示钱包登录入口；不在页面加载时请求签名 |
| AC-003-04 | 用户连接钱包并批准 SIWE | 请求 challenge/verify，携带 Cookie，随后加载当前钱包关系 |
| AC-003-05 | 后台配置非 Fuji、钱包拒绝或响应结构错误 | 显示可理解错误，不更新为成功状态 |
| AC-003-06 | API 返回金额字符串、Unix 秒和链状态 | 精确映射为前台金额、毫秒时间、角色及页面状态 |
| AC-003-07 | API 模式点击尚未实现的业务写入 | 明确提示需要合约或后台写接口，不使用 Mock 改状态 |

## 验证

运行 `npm run typecheck`、`npm test`、`npm run build`。单元测试注入模拟 fetch 与 EIP-1193 provider，覆盖 401、SIWE、Cookie、数据映射和禁止假写入；浏览器以 API 模式、无后台场景检查连接页面。真实后台联调、真实 SIWE 会话和链上交易在后台/合约实现可用后继续验收。
