## 失败及修复记录

1. 首次类型检查/构建发现拆分后的未使用导入、Avatar误用灰阶名 `sand`，以及仅安装web工作区导致根依赖缺失。删除无用导入，Avatar使用合法 `gray` 色名，执行根目录 `npm ci` 后类型检查和构建通过；未改业务代码。
2. 新键盘测试首次未等待Select的初始选项聚焦就发送方向键；增加选项聚焦断言后操作稳定。随后该新测试对争议预设已经选中的好友1再次选择，却错误期待“已切换”提示；改为实际切换到好友2并断言身份，保留“切换后提示”验证。两次失败trace及上下文分别保存在本地 `artifacts/verification/radix-keyboard-first/` 和 `radix-keyboard-second/`，原有业务测试始终保留。
3. 额外320px检查发现首页纸页宽度溢出；纸页改为随容器缩放，并新增七路由320px回归用例。
4. 人工截图发现Portal独立Theme未匹配原 `.demo-theme` 选择器，沿用默认白底、亮绿与阴影；将品牌变量和弹层样式作用于所有Radix Theme根，增加实际计算样式断言。最终13项浏览器用例全部通过。

以上结果为本地UI回归与自检；PR是否合并以远程状态为准，未部署云服务器。
