# 接口与数据约定

状态：待业务定义。这里的 contracts 同时涵盖数据契约、应用 API 和智能合约接口；目前没有已实现接口或已部署合约。

## 公共约定

以下为使用 C-Chain 时的建议约定，在 T002 确定技术路线后落实：

- Chain ID 在配置中使用整数，JSON-RPC 表示遵循十六进制格式；Fuji 参数见 [生态文档](ecosystem.md)。
- 地址和交易哈希作为字符串传递，调用前校验格式；不能仅凭格式判定链上存在。
- 金额在内部使用最小单位整数；经过 JSON 时使用十进制字符串，避免浮点精度损失。显示时按资产 decimals 转换。
- 链上时间与应用时间的单位必须在字段定义中注明。
- 错误要区分输入错误、钱包拒绝、网络错误和链上执行失败，保留必要的诊断信息。
